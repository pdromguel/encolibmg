# Fase 5 — Guia MIDI: plano de implementação

> Execução: nativa, TDD por tarefa. Fases 6 e 7 ganham plano próprio depois que a 5 for verificada no Encore.

**Goal:** gerar `X.guide.mid` (notas + palavras temporizadas) para faixas Multiplex, com prévia e integração na GUI.
**Spec:** [docs/specs/2026-10-25-fases5-7-design.md](../specs/2026-10-25-fases5-7-design.md)

## Global Constraints
- MIDI: formato 1, 480 PPQ, 120 BPM fixo; canal 1, programa 73, CC7=0, `@IVOCAL-CH=1`; letra em eventos 0x05 UTF-8.
- `/` antes da 1ª palavra de cada linha (exceto a primeira); `{#TITLE=…}{#ARTIST=…}` no tick 0.
- Notas: mín. 90 ms; junta iguais com gap < 80 ms; troca de nota > 0,8 st por ≥ 60 ms; silêncio ≥ 50 ms fecha nota.
- 1ª palavra de cada linha = tempo do `.lrc`.

## Review Focus
1. Linha do `.lrc` sem letras alinháveis ("(Ah ah ah)", "♪", só números) → plano B, nunca exceção; teste Task 3.
2. Última linha sem "próxima linha" → janela até o fim do áudio (máx. 8 s); teste Task 3.
3. Letra com menos de 6 palavras no total → guia teria ≤ 5 eventos e o Encore ignoraria as notas: completa com
   eventos vazios? Não — recusa com mensagem clara; teste Task 4.
4. Faixa sem `.lrc` ou não-Multiplex → botão desabilitado e erro claro no `build`; teste Task 5.
5. Regerar guia já existente → substitui (backup do antigo); teste Task 5.

### Task 1: `guide/melody.py`
**Produces:** `Note(start:float, end:float, pitch:int)`, `f0_to_notes(times, f0_hz, voiced: np.ndarray[bool]) -> list[Note]`,
`fix_octaves(notes)->list[Note]`, `clip_to_windows(notes, windows: list[tuple[float,float]])->list[Note]`,
`extract_f0(vocals: np.ndarray, sr:int, device=None) -> (times, f0, periodicity, loudness_db)`,
`detect_notes(vocals, sr, windows) -> list[Note]`.
- Testes sintéticos (sem CREPE): escada com vibrato; buraco 40 ms; nota < 90 ms descartada; merge; oitava; janelas.
- `slow`: `extract_f0` num seno de 220 Hz → ≈ 220.

### Task 2: `guide/romanize.py`
**Produces:** `script_of(text)->'latin'|'ja'|'ko'|'other'`, `words_for_alignment(line) -> list[tuple[display:str, roman:str]]`,
`furigana(display) -> str` (`漢字[かんじ]` se houver kanji).
- Testes: "Águas de Março" → roman "aguas","de","marco"; "君の名は" → trechos pykakasi com romaji; "사랑해" → "saranghae";
  pontuação removida do roman mas mantida no display; palavra só com símbolos → roman "".

### Task 3: `guide/align.py`
**Produces:** `Word(start:float, text:str)`, `line_windows(lines: list[Line], audio_end:float)->list[tuple]`,
`fallback_words(words, start, end, onsets)->list[float]`, `align_line(vocals16k, start, end, words, aligner)->list[float]|None`,
`align_lyrics(vocals, sr, lines, notes, aligner=None)->list[list[Word]]`.
- `aligner` injetável (o real usa MMS_FA); testes com aligner falso: aceito, rejeitado (fora de ordem / score baixo) → plano B;
  1ª palavra = tempo do LRC; linha sem roman → plano B; última linha janela ≤ 8 s.

### Task 4: `guide/midi.py`
**Produces:** `write_guide(path, notes, lines: list[list[Word]], title, artist)`, `read_guide(path)->GuideInfo(notes, lyrics: list[(sec,text)], vocal_ch)`.
- Testes de ida e volta conforme Global Constraints; furigana; < 6 eventos → `ValueError`.

### Task 5: `guide/build.py` + biblioteca/checker
**Produces:** `build_guide(lib, track, on_progress=None, cancel=None, aligner=None, f0_fn=None) -> Track`; `Track.has_guide`;
`kind_label` "+ guia"; checker kind `no_guide` (corrigível); pipeline `add_song`/`track_from_local`/`convert_to_multiplex` com `make_guide=True`.
- Testes com dependências falsas; backup ao regerar; erros para faixa sem lrc / não multiplex.
