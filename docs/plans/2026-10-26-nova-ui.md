# EncoLibMG — nova interface: plano de implementação

> Execução: nativa, por tarefa, com prints reais da janela ao fim de cada tela. O motor Python não muda.

**Goal:** trocar a casca Tk por uma janela WebView2 com a identidade EncoLibMG e efeitos de pixel, cobrindo tudo que a
interface atual faz.
**Spec:** [docs/specs/2026-10-26-nova-ui-design.md](../specs/2026-10-26-nova-ui-design.md)
**Stack:** pywebview 6.2.1 · lit-html 3.3.3 (vendorizado) · JetBrains Mono (vendorizada, OFL) · Canvas 2D · stdlib http.server.

## Global Constraints
- Nada é baixado em tempo de execução (fontes, lit-html e marca vêm no pacote). Exceção: miniaturas do YouTube.
- Servidor: só `127.0.0.1`, porta aleatória, token por sessão (cookie + query), `/media` apenas dentro das raízes
  permitidas (biblioteca aberta, pasta temporária do importador), suporte a `Range`.
- API: toda resposta é `{"ok": true, "data": …}` ou `{"ok": false, "error": str, "kind": str}`; nunca exceção crua.
- Um trabalho pesado por vez; eventos de progresso limitados a 20/s.
- Tokens de cor, raio 0, célula 10px/gap 1px, voz em português curta (spec).
- `prefers-reduced-motion` respeitado em todos os efeitos; canvas pausado com a janela oculta.

## Review Focus
1. Biblioteca não aberta → todas as telas mostram um estado vazio com "Abrir/Criar biblioteca", nunca erro (T4–T9).
2. Caminho com acentos/espaços/`#` na URL de mídia → toca normalmente (T1, teste com `Águas de Março #2.mp3`).
3. Trabalho rodando e usuário troca de tela → o progresso continua no rodapé e o resultado chega (T2).
4. Lista grande (2.000 faixas) → filtro instantâneo, sem travar (T6: renderização em janela/virtualizada).
5. `/media` com `..` ou caminho absoluto de fora → 403 (T1).

### T1 — Ponte Python (server, jobs, api, janela)
**Files:** `encolibmg/webui/{__init__,app,server,jobs,api,views}.py`, `encolibmg/__main__.py`, `tests/test_webui_*.py`
- `server.py`: `UIServer(static_dir, token)`, `.start() -> base_url`, `.allow(root: Path)`, `.media_url(path) -> str`.
  Handler: `/` e estáticos (MIME corretos, `.mjs/.js` = text/javascript), `/media/<quoted path>` com Range (206).
- `jobs.py`: `JobManager(emit)`: `start(label, fn) -> id` (erro `Busy` se já houver), `cancel()`, progresso
  throttled → `emit("job", {...})`.
- `api.py`: `Api(server, jobs)` com todos os métodos listados no fim deste plano; `_wrap` gera `{ok,…}`.
- `app.py`: `run()` cria a janela (título "EncoLibMG", ícone, fundo `#101315`, 1180×780, mín. 900×600), injeta
  `emit` via `window.evaluate_js("window.encolib && encolib.emit(...)")`. Sem WebView2 → aviso + Tk.
- `__main__`: web por padrão; `--tk` abre a antiga.
- Testes: token obrigatório; Range 206 + bytes certos; `..`/fora → 403; MIME; jobs (progresso, cancel, Busy);
  api.state/tracks/search com fakes.

### T2 — Fundação do front-end
**Files:** `static/index.html`, `css/{tokens,base,components,views}.css`, `vendor/lit-html.js`, `fonts/*`,
`js/{app,api,store,router,keys}.js`, `js/ui/{header,dock,toast,modal,empty,kbd}.js`
- `api.js`: `call(name, ...args)` → Promise (desembrulha `{ok}`; erro vira toast + throw); `on(event, fn)`.
- `store.js`: estado global + `subscribe`; `router.js`: rotas `#/home,#/add,#/library,#/check,#/import,#/visual,
  #/sync/:base,#/guide/:base` com transição de pixels.
- Cabeçalho: marca (canta enquanto há job), links com sublinhado animado, botão Configurar, nome da biblioteca.
- Rodapé (dock): barra de progresso pixel, etapa, %, Cancelar; mini player.
- Atalhos `/ 1-6 Esc ? Ctrl+O`; tela de ajuda.

### T3 — Efeitos de pixel
**Files:** `js/fx/{pixel-font,wordmark,field,mark,progress,transition,identicon,equalizer,confetti,typer}.js`,
`tests/js/*.test.mjs`
- `pixel-font`: grades de `brand.json`; `textGrid(str)`.
- `field`: campo com densidade nas bordas, cristas, rastro em losango, anel no clique; redesenho só das células
  sujas; pausa em `visibilitychange`.
- `wordmark`: montagem + tremor perto do mouse + varredura.
- `mark`: marca estática/"cantando" (loader).
- `identicon(name)`: 5×5 simétrico, determinístico (FNV-1a), 2 tons.
- `progress`: preenchimento de karaokê determinado/indeterminado.
- `transition`: dissolve em blocos (~280 ms). `confetti`, `equalizer`, `typer`.
- Testes Node (`node --test`): textGrid, identicon (estável, simétrico), ordem do dissolve cobre tudo.

### T4 — Início
Campo + wordmark; busca grande com `typer`; números da biblioteca (links); recentes com identicons; estado sem
biblioteca (Abrir/Criar com colchetes de canto).

### T5 — Adicionar
Busca com resultados animados (stagger), selo ✓, duração; Baixar completa (Gerar guia), MTV com seletor de vídeo
com miniaturas (`i.ytimg.com/vi/<id>/mqdefault.jpg`) e marca de duração; confete ao terminar; erros com caminho
(sem áudio → oferecer MTV).

### T6 — Biblioteca + painel da faixa + mini player
Lista com filtro/ordenação/seleção múltipla (virtualizada); selos; ações em massa. Painel lateral: identicon,
arquivos, ouvir (Web Audio: ambos/instrumental/voz), Sincronia, Prévia do guia, Gerar guia, Editar, Clipe,
Converter, Remover.

### T7 — Sincronia e Prévia do guia
- API `sync_load` devolve linhas, URL do áudio, duração e **picos da voz** (≈ 2.000 pontos). Tela com forma de onda
  em pixels, marcadores das linhas, playhead, seek por clique/arraste, ±, âncoras (Espaço), sugerir, salvar,
  desfazer, regerar guia.
- API `guide_load` devolve notas e palavras; tela com rolo de piano em pixels + linha de karaokê preenchendo.

### T8 — Verificar e Importar
Verificar: botão, opção volume, grupos por tipo com contagem, corrigir selecionados/tudo, resultado por linha.
Importar: escolher pasta (diálogo nativo), prévia editável inline, opções, importar com status por linha.

### T9 — Visual e som + Configurar
BGV (categorias, miniaturas por `<video preload=metadata>`, do PC/YouTube), imagens de espera (grade), vídeo de
abertura (player), narrações (▶), SoundFont; modal Configurar (nome, descrição, opções).

### T10 — Acabamento e verificação
Prints de todas as telas na janela real (`scripts/snap.py` adaptado para a app), zero erros de console, teste com
`prefers-reduced-motion`, medição de quadro do campo (< 2 ms), README com a marca, remover Tk se tudo coberto
(fica `--tk` por uma versão).

## API (Python ↔ JS)
| Método | Devolve |
|---|---|
| `state()` | `{version, library: {path,title}|null, stats: {tracks, guides, issues?}}` |
| `library_pick()`, `library_create(title)`, `library_open(path)` | `state` |
| `tracks()` | `[{base, artist, title, kind, label, badges[], files[{name,size}], has_guide, has_video, multiplexed, mtime}]` |
| `search_lyrics(q)` | `[{id, artist, title, album, duration, synced}]` (cacheados no servidor por id) |
| `add_song(id, make_guide)`, `find_mtv(artist,title)`, `add_mtv(artist,title,video)` | job id / vídeos |
| `job_cancel()` | — |
| `track_rename(base, artist, title)`, `track_remove(bases)`, `track_convert(base)`, `track_guides(bases)` | track / job |
| `find_clip(base)`, `add_clip(base, video)` | vídeos / job |
| `media(base, which)` | URL `/media/...` (`which`: audio, video) |
| `sync_load(base)`, `sync_save(base, lines)`, `sync_undo(base)`, `sync_suggest(base)` | dados / ok |
| `guide_load(base)` | `{notes, lyrics, audio, duration}` |
| `check(loudness)`, `fix(ids)` | job → issues / resultados |
| `import_pick()`, `import_scan(folder)`, `import_edit(i, artist, title, selected)`, `import_run(opts)` | itens / job |
| `visual_state()`, `bgv_*`, `bumper_*`, `boot_*`, `narration_*`, `soundfont_*` | estado visual |
| `settings_get()`, `settings_save(data)` | manifest |
| `open_path(rel)`, `pick_files(kind, multiple)` | — / caminhos |

Eventos Python → JS: `job` (`start/progress/done/error/cancelled`), `library` (mudou).
